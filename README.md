# Abhikhya Architects & Interior Design Studio

Official website for **Abhikhya Design Studio**, a multidisciplinary architecture and interior design firm based in Greater Noida & Delhi NCR, India.

## Features
- **Editorial Architectural Layout**: Minimalist aesthetics, typography, fluid animations, and responsive layouts.
- **Interactive Projects Archive**:
  - Filter by Category: `All`, `Architecture`, `Art`, `Design`
  - Filter by Location: Greater Noida, Noida, Delhi NCR, Ghaziabad
  - Filter by Typology: Celebrity Residence, Elevation & Architecture, Residential Interior, Commercial, Hospitality
  - Grid & List view toggle
  - In-place Project Story Modals detailing specifications, timeline, location, and architectural narratives
- **Studio Pages**:
  - Home Page with curated showcase and process breakdown
  - Dedicated About Us page
  - Contact page with direct consultation form, inquiry channels, and Google Maps embed
- **Performance Optimized**:
  - WebP/AVIF modern image formats
  - Dual-stack high-performance HTTP server
  - Self-hosted subset fonts

## Quick Start

### 1. Requirements
- Node.js (v18+)

### 2. Run the Website
```bash
node server.js
```
The website will start at:
- **Local**: [http://localhost:3001](http://localhost:3001)
- **Direct**: [http://127.0.0.1:3001](http://127.0.0.1:3001)
